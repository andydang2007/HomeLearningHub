# Home Learning Hub - 家长指南 / Parent Guide

> 这份指南写给家长，帮助你快速了解这个系统怎么用、每个功能有什么作用。
>
> This guide is for parents. It explains how the system works and what each feature is for.

---

## 1. 这个系统是做什么的？ / What Is This For?

Home Learning Hub 是一个给新加坡小学家庭使用的学习奖励系统。

孩子每天完成短练习，获得徽章、金币、个人水晶和奖励游戏机会。家长负责设置规则、查看学习报告、管理奖励，并审批孩子的兑换申请。

Home Learning Hub is a learning and reward system for primary-school families in Singapore.

Children complete short daily practice sessions and earn badges, coins, personal crystals, and reward game chances. Parents set the rules, view learning reports, manage rewards, and approve redemptions.

核心目标不是让孩子无限刷题，而是帮助孩子建立稳定、轻量、可坚持的学习习惯。

The goal is not endless drilling. The goal is to build a light, steady learning habit that children can keep.

## 2. 账户类型 / Account Types

注册账户有两个家庭类型：

- **一孩账户**：只能添加 1 个孩子。
- **多孩账户**：最多添加 3 个孩子。

There are two family account types:

- **Single-child account**: add 1 child only.
- **Multi-child account**: add up to 3 children.

每种家庭类型都有基础版和高级版。基础版和高级版的功能范围相同；主要差别是家庭类型能添加几个孩子，以及对应价格不同。

Both account types can have Basic or Premium plans. The feature set is the same; the main differences are how many children can be added and the price.

---

## 3. 三种奖励：金币、水晶、徽章 / Coins, Crystals, and Badges

### 金币 / Coins

金币用于兑换实物奖励，例如快餐、零食、文具、玩具、书籍等。

孩子每获得 1 个徽章，就对应获得 1 个金币。

Coins are used for physical rewards, such as fast food, snacks, stationery, toys, and books.

Each badge earned gives 1 coin.

### 个人水晶 / Personal Crystals

个人水晶属于每个孩子自己，主要用于兑换非实物奖励，例如电影之夜、周末露营、免做家务、额外游戏时间、家庭活动等。

孩子当天至少获得 1 个徽章后，才能解锁当天打卡水晶。

Personal crystals belong to each child. They are mainly used for non-physical rewards, such as movie night, weekend camping, skipping a chore, extra game time, or family activities.

A child unlocks the daily check-in crystal after earning at least 1 badge that day.

### 徽章 / Badges

徽章记录孩子完成了什么、坚持了多久、在哪些方面做得好。

徽章会显示在孩子的徽章墙上。升级等级或段位时，可能会消耗已经获得的徽章和/或个人水晶。

Badges show what a child has completed, how consistent they have been, and where they did well.

Badges appear on the child’s badge wall. Upgrading levels or tiers may use some earned badges and/or personal crystals.

## 4. 第一次使用 / First-Time Setup

### 家长先做这些 / For Parents

1. 由家长 / 监护人注册家庭账号。孩子不需要、也不能用邮箱注册账号。
2. 设置家长 PIN。这个 PIN 用来保护家长后台。
3. 按账户类型添加孩子档案：一孩账户 1 个，多孩账户最多 3 个。
4. 为每个孩子设置昵称、年级、默认头像、华文或高级华文、界面语言。学校名和性别可以不填。
5. 为每个科目设置基础正确率、目标正确率和目标完成时间。
6. 为每个科目设置出题范围。
7. 添加可兑换奖励。

1. A parent or guardian creates the family account. Children do not need, and cannot use, email registration.
2. Set a parent PIN to protect the parent area.
3. Add child profiles based on your account type: 1 child for a single-child account, up to 3 children for a multi-child account.
4. Set each child’s nickname, grade, default avatar, Chinese level, and interface language. School name and gender are optional.
5. Set the base accuracy, target accuracy, and target completion time for each subject.
6. Choose the question range for each subject.
7. Add rewards that children can redeem.

### 孩子怎么开始 / For Children

孩子打开学生端，选择自己的头像，进入首页，然后选择科目开始练习。

Children open the student area, choose their avatar, enter the home page, and start a subject practice.

## 5. 注册前可以先玩吗？ / Can Children Try Before Registration?

可以。

注册前，孩子可以先在当前设备上玩，系统会把学习记录暂存在这台设备上。

但请注意：如果更换设备、清空浏览器缓存，或修改孩子昵称，注册前的数据可能会丢失。

Yes.

Before registration, children can try the system on the current device. Their progress is stored on that device.

Please note: before registration, progress may be lost if you change device, clear browser data, or change the child’s name.

注册后，学习记录会保存到家庭账号下。换设备登录后，孩子的徽章、金币、水晶、打卡和练习状态都会跟着回来。

After registration, progress is saved under the family account. When you log in on another device, badges, coins, crystals, check-ins, and practice status will follow.

## 6. 每日练习怎么安排？ / How Daily Practice Works

每场标准练习有 15 题：

- 错题复习：优先帮助孩子把以前做错的题做对。
- 降维复习：少量低一年级题，巩固基础。
- 当前年级题：根据孩子年级和家长设置的出题范围出题。

Each standard practice has 15 questions:

- Mistake review: helps the child practise questions they previously got wrong.
- Lower-grade review: a small number of easier questions to strengthen the foundation.
- Current-grade questions: questions based on the child’s grade and the range set by the parent.

每天每科正式练习只计算一次。必须做完最后一题，才算今日完成。中途退出不会锁住当天练习。

Each subject counts once per day. A session only counts after the final question is completed. Leaving halfway does not lock the child out for the day.

完成练习并达到该科基础正确率后，孩子可以获得 1 个科目徽章。每获得 1 个徽章，就获得 1 个金币。

When a child completes practice and meets the subject’s base accuracy, they can earn 1 subject badge. Each badge earned gives 1 coin.

如果孩子达到家长设置的目标正确率，并在目标时间内完成，还可以获得额外徽章。

If the child reaches the target accuracy set by the parent and finishes within the target time, they can earn extra badges.

当天至少获得 1 个徽章后，孩子可以解锁当天打卡水晶。

After earning at least 1 badge that day, the child can unlock the daily check-in crystal.

## 7. 孩子身份 PIN / Child PIN

孩子身份 PIN 是给多孩家庭用的可选保护。

它的目的不是防止孩子“偷走”别人已有的奖励，而是防止大孩子进入小孩子账号做低年级题，刷出金币去骗奖励，也可能把小孩子当天的练习机会用掉。

The child PIN is an optional protection for families with more than one child.

Its purpose is not to stop a child from taking someone else’s existing rewards. It prevents an older child from entering a younger child’s profile, doing much easier questions, generating coins under that profile, and using them to claim rewards. It may also use up the younger child’s daily practice chance.

你可以为每个孩子单独开启或关闭 3 位身份 PIN。单孩家庭通常不需要开启。

You can turn a 3-digit child PIN on or off for each child. Single-child families usually do not need it.

## 8. 各科出题范围 / Question Range for Each Subject

每个科目都可以为每个孩子设置出题范围。

Each subject can have its own question range for each child.

### 家长点选范围 / Parent-Selected Range

默认模式下，家长为每个科目点选孩子当前学到的 topic、chapter 或 lesson，系统按这些范围出题。

适合跟学校进度走的孩子，也适合不想太早遇到未学内容的家庭。

By default, parents select the topic, chapter, or lesson that the child is currently learning for each subject. The system uses those selected areas.

This is suitable for children following school pace, or families who do not want the child to meet content too early.

### 全年题库无限制 / Full-Grade Unrestricted

系统可以从孩子当前年级的全部题库里出题。

适合程度较好、已经走在学校前面、需要更多练习空间的孩子。

The system can use the full question set for the child’s current grade.

This is suitable for stronger children who are ahead of school pace and need more practice space.

这个设置适用于所有科目。

This setting applies to all subjects.

## 9. 英文和华文听写 / English and Chinese Dictation

听写有两种来源：

There are two dictation sources:

### 系统默认听写表 / Default Dictation Lists

即使你没有上传任何材料，孩子也可以使用系统默认听写表。

Even if you do not upload any materials, the child can use the default dictation lists.

### 你上传的学校听写表 / Your Uploaded School Lists

你可以上传学校给的英文或华文听写表。系统识别后，会先让你确认和修改，再给孩子使用。

You can upload English or Chinese dictation lists from school. After recognition, you can review and edit the items before your child uses them.

你上传的内容只属于这个孩子，不会进入其他家庭的题库。

Your uploaded content belongs only to that child. It will not be shared with other families.

## 10. 错题是怎么用的？ / How Mistakes Are Used

孩子不会看到一个单独的“错题本”页面，也不需要自己管理错题。

系统会在后续练习中自动抽到合适的错题。孩子只需要把题做对。

Children do not see or manage a separate mistake-book page.

The system automatically brings suitable mistake questions back into future practice. The child only needs to answer them correctly.

家长可以在学习报告里看到错题细节，包括孩子当时填了什么错误答案、正确答案是什么。

Parents can see mistake details in the learning report, including the child’s wrong answers and the correct answers.

## 11. 学习报告 / Learning Reports

学习报告帮助你快速了解孩子这一周学得怎么样。

报告会显示：

- 完成了多少次练习。
- 正确率大致如何。
- 新获得了多少徽章。
- 金币和个人水晶的变化。
- 学习时长。
- 错题变化。
- 典型错题和孩子写过的错误答案。

Learning reports help you quickly understand how your child did during the week.

Reports show:

- How many practice sessions were completed.
- General accuracy.
- New badges earned.
- Coin and personal crystal changes.
- Learning time.
- Mistake changes.
- Typical mistake questions and the child’s wrong answers.

你可以一键保存报告为 PDF。

系统内只保留最近一周的报告，避免长期堆积。需要长期保存时，请把 PDF 存到自己的设备上。

You can save the report as a PDF with one click.

Only the most recent week of reports is kept inside the system to avoid long-term clutter. If you want to keep a report longer, save the PDF to your own device.

孩子可以用奖励资产申请兑换。

个人水晶主要兑换非实物奖励，例如电影之夜、周末露营、免做家务、游戏时间、家庭活动。

Children can request rewards using earned assets.

Coins are mainly for physical rewards, such as fast food, snacks, stationery, toys, and books.

Personal crystals are mainly for non-physical rewards, such as movie night, weekend camping, skipping a chore, game time, or family activities.

孩子提交兑换后，家长会在后台看到申请。你可以批准，或拒绝并退款。

After a child requests a reward, you will see it in the parent area. You can approve it, or reject it with a refund.

## 13. 奖励游戏 / Reward Games

奖励游戏是孩子完成学习后的 2-3 分钟短暂放松。

孩子需要通过合格练习获得机会，不能直接打开游戏入口。

Reward games are short 2-3 mins breaks after learning.

Children need to earn access through valid practice. They cannot open the game area directly.

## 17. 隐私与安全 / Privacy and Safety

孩子只使用昵称，不鼓励填写真实姓名。

学校名和性别由家长选择是否填写；不填写也可以正常使用。

当前版本不允许上传真人头像，只使用系统默认头像。

除了家长主动填写的资料和孩子使用系统时产生的学习记录外，系统不会额外收集孩子的信息。

你上传的听写表、错题和自定义内容只属于指定孩子，不会分享给其他家庭。

Children use nicknames. Real full names are not encouraged.

School name and gender are optional. The system works without them.

The current version does not allow real photo avatar uploads. Children use default system avatars.

The system does not collect a child’s information other than what parents key in and the learning records created when the child uses the system.

Uploaded dictation lists, mistake materials, and custom content belong only to the selected child and are not shared with other families.

学习报告 PDF 只在系统内短期保留。家长可以自行保存需要长期保留的报告。

Learning report PDFs are kept in the system only for a short time. Parents can save reports they want to keep longer.

家长可以请求导出、更正或删除孩子资料。

Parents can request to export, correct, or delete a child’s data.

## 18. 常见问题 / FAQ

### 换设备会丢数据吗？ / Will progress be lost on a new device?

注册后不会。登录同一个家庭账号即可恢复。

Before registration, progress is stored only on the current device. After registration, log in with the same family account to restore progress.

### 孩子今天中途退出，还能再练吗？ / Can my child continue if they leave halfway?

可以。必须完成最后一题，才算今日完成。

Yes. The session only counts after the final question is completed.

### 上传的听写表会给别人用吗？ / Will my uploaded dictation list be shared?

不会。只给你选择的孩子使用。

No. It is only used for the child you selected.

### 孩子能自己改奖励或 PIN 吗？ / Can children change rewards or PINs?

不能。奖励设置、审批和 PIN 管理都在家长后台。

No. Reward settings, approval, and PIN management are handled in the parent area.

### 孩子可以自己用邮箱注册吗？ / Can children register with email?

不能。家庭账号只能由家长或监护人注册。孩子只使用家长创建的孩子档案。

No. Family accounts can only be created by a parent or guardian. Children only use child profiles created by the parent.

### 系统能完全防止孩子乱答题吗？ / Can the system fully stop careless answering?

不能完全防止。系统可以管理练习、错题和奖励流程，但真正有价值的奖励仍需要家长审批。

Not completely. The system manages practice, mistakes, and rewards, but meaningful rewards still require parent approval.
